# TrackFlow Logistics Landing Page

Landing page corporativa moderna para **TrackFlow**, una empresa de logística y gestión de almacenes con operaciones en Estados Unidos y España.

El proyecto fue desarrollado como una experiencia web responsive, visualmente moderna y optimizada para presentar los servicios, capacidades tecnológicas y propuesta de valor de la empresa.

---

## Vista General

TrackFlow ofrece:

- Gestión de almacenes
- Logística de última milla
- Logística inversa
- Automatización operativa
- Visibilidad ejecutiva en tiempo real
- Operaciones internacionales

La landing fue diseñada para transmitir una imagen tecnológica, premium y escalable orientada a empresas de e-commerce.
Se incluye un formulario para enviar un mail a modo de consulta o solicitud(empresa o cliente).
---

## Características

### Diseño UI/UX
- Diseño moderno y responsive
- Estética dark premium
- Navegación smooth scroll
- Animaciones reveal on scroll
- Efectos hover interactivos
- Feedback visual en botones y tarjetas
- Parallax hero section
- Mobile-first responsive navbar

### Internacionalización (i18n)
- Traducción dinámica Español ↔ Inglés
- Persistencia de idioma con `localStorage`
- Sistema basado en `data-translate`
- Traducción de:
  - navegación
  - secciones
  - formularios
  - mensajes de error
  - contenido dinámico

### Formulario de Aplicación
- Validación de campos
- Validación de contraseñas
- Validación de email y teléfono
- Mensajes de error dinámicos
- Estados de éxito
- Diseño responsive

### SEO & Accesibilidad
- Meta tags optimizados
- Open structure semántica
- JSON-LD Structured Data
- Alt text descriptivo
- Navegación accesible
- Preferencias de reducción de movimiento

## Tecnologías Utilizadas
